Long time no see!

I've been having a lot a trouble on schoolwork and time recently, so no time for blogs, during the Qing Ming Festival Break in China **(Similiar to Mexico's Day of the Dead but not quite)**, I finally can have a little break where I can make projects I like!

As I said before, I am obsessed with old games and old tech, which led me to think about old Online Multiplayer Games such as GMOD, Counter Strike 1.6, Source and more, so I thought: Why not make a old Game server to bring that sense of nostalgia back? Well I did it, looking for tutorials and asking on the AlliedModders Forum for a lot of time, and setting up all kinds of plugins. Now what I Have is a Full On DeathMatch Server running on my old Thinkpad with Upgraded 8 GB RAM and 128GB SSD, which working amazingly good in 2023!

I Will Post The ***IP Address of my server*** Later in the Month, and I wish you all a good holiday!

:3

## The next day: the link, and more

So as I promised, here's the banner of my server, including the ip address of my CSS Server — it was a GameTracker badge pointing at my home connection on port 27015.

Oh and also my server has SourceMod, MetaMod, and some plugins Installed on it, I have a list of the plugins at the bottom of this page if you guys want to see for yourself, it is really just a few files and the SourceMod Plugins command just shows all of the files associated with each plugin.

Anyways the way I got the server running over my network was pretty frustrating, I will come up with a tutorial on How to build a Source Dedicated Server and how to setup a NAT Reverse Proxy. I would also consider opening more Source/HLDS Servers from different games and test it out myself! I've filtered the possible candidates for the server creation which are: Lead 4 Dead 2, HL2 DM, TF2, and maybe GMOD.
